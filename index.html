スクーミー Scratch拡張機能

v2.0 ／ 担当者向け手順書

これは何か

オレンジボードのセンサーの値をScratchで受け取り、さらに複数の班の値を1台のPCに集めて合計や平均を出すための拡張機能です。スイッチを押した回数を数える使い方も、温度を持ち寄る使い方も、同じ仕組みで動きます。

拡張機能のURL

Scratchに読み込ませるURLです。このページではなく、下のアドレスを使ってください。

https://shiojima-test.github.io/schoomy-scratch-extension/schoomy_sensor_v2_0.js

読み込み手順

  1. スクーミーワールドスクラッチ を開く
  2. 画面左下の「拡張機能を追加」ボタンを押す
  3. 一覧のいちばん最初にある「Choose an extension（For developers）」を選ぶ
  4. URL入力欄が出るので、上のアドレスを貼り付けてOK
ブラウザはChromeまたはEdgeを使ってください。Web Serialに対応していないブラウザではボードに接続できません。

共有サーバーの準備

班をまたいで値を集めるには、中継役のサーバーが1つ必要です。イベントごとに1回だけ用意します。

  1. script.google.com で新しいプロジェクトを作る
  2. このリポジトリの gas/Code.gs の中身をすべて貼り付ける
  3. 「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」
  4. 実行するユーザー＝自分、アクセスできるユーザー＝全員
  5. 発行された /exec で終わるURLを控える
このURLを知っている人は誰でも値の書き込みとリセットができます。一般公開はせず、イベント担当者のみで扱ってください。班のScratchファイル（.sb3）を配布すると、その中にURLが残ります。

Scratchの組み方

班側のPC（オレンジボードを接続する）

緑の旗が押されたとき 共有サーバーを〔控えたURL〕にする 班を〔A〕にする オレンジボードに接続する（USB） 変数「自分の数」を 0 にする スイッチが押されたとき 変数「自分の数」を 1 ずつ変える 自分の値〔自分の数〕を送る

班ごとに「班を〔　〕にする」の中身だけを変えます。A・B・Cでも、1組・2組でも、チーム名でもかまいません。事前の班数登録は不要です。

集計用のPC（ボードは不要）

緑の旗が押されたとき 共有サーバーを〔控えたURL〕にする ずっと 共有データを取り込む 1 秒待つ

あとは「合計」「平均」「班の数」などのブロックにチェックを入れて画面に表示するか、「〔　〕番目の班の名前」「〔　〕番目の班の値」を使って班の一覧を描いてください。

温度など、数え上げ以外に使う場合

「スイッチが押されたとき」は使わず、次のようにします。

緑の旗が押されたとき 共有サーバーを〔控えたURL〕にする 班を〔A〕にする オレンジボードに接続する（USB） ずっと 自分の値〔センサーデータ〕を送る 3 秒待つ
「スイッチが押されたとき」は、値が0から0以外に変わった瞬間だけ反応します。温度センサーのように常に値が流れ続けるセンサーでは反応しません。

うまくいかないとき

症状確認すること
ボードにつながらないChromeまたはEdgeか。他のタブやスクーミーブロックエディタが同じボードをつかんでいないか
値が0のまま動かないボード側のプログラムが値を送る状態になっているか。「センサーデータ」を画面に出して確認
1回押しただけで数字が飛ぶ「データを受信したとき」ではなく「スイッチが押されたとき」を使っているか
合計が変わらない「エラー内容」を画面に出す。URLの末尾が /exec か。GASのアクセス権が「全員」か
コードを直したのに反映されないGASは「新しいデプロイ」をやり直さないとURLの中身が変わりません
